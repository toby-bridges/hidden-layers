# Hidden Layers

[Play the six-layer glasswing journey](https://toby-bridges.github.io/hidden-layers/). Scroll or swipe vertically to fly, move sideways to steer and tap **Sound off** to start the synthesized soundscape.

This repository serves the static build of an independent Three.js implementation. The premise and creative brief were adapted from [ky-zo/fable-butterfly](https://github.com/ky-zo/fable-butterfly/tree/3f717953b78c36c9d0dc61be04ac55267563c152).
